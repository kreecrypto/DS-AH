# 05 Surface — Look & Feel

Apply the approved design system without changing underlying UX intent.

## Required knowledge
Design tokens, typography, color, spacing, grid, components, icons, visual hierarchy, component states, motion and accessibility.

## Agent checks
Use existing tokens/components first. Do not invent a new design language when an approved system exists. Verify contrast, states, hierarchy, consistency, density and visual regression against references.

## Output
Production-ready visual specification and Figma implementation guidance.
