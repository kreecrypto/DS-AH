# 02 Scope — What

Translate Strategy into explicit product requirements.

## Required knowledge
Functional and content requirements; features; use cases; user stories; acceptance criteria; business rules; permissions; constraints; states and edge cases.

## Agent checks
What must the system support? What is intentionally excluded? What rules constrain behavior? What permissions exist? What happens in loading, empty, error, disabled, partial, timeout and permission-restricted conditions?

## Output
Requirement set, use cases, business rules, state matrix, edge cases and acceptance criteria.
