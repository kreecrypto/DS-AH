# UX Writing

## Goal
Help users understand state, consequence and next action with minimal cognitive effort.

## Principles
Clear before clever. Use the user's vocabulary. Prefer specific verbs. Keep labels stable across the flow. State consequences before destructive or irreversible actions. Explain errors with recovery guidance.

## Component guidance
Buttons: describe the action (Save changes, Export members).
Headings: orient the user and task.
Helper text: answer likely uncertainty before failure.
Errors: what happened + where relevant why + how to recover.
Empty states: explain the state and provide the next meaningful action.
Confirmation: state what changed and whether further action is required.

## Avoid
Vague CTAs such as OK/Submit when a precise action exists; blame; unexplained technical codes; redundant instructions; inconsistent terminology.

## Review
Check comprehension, action clarity, terminology consistency, localization expansion and accessibility of instructions.
