# UX Pattern Library

Reusable interaction knowledge. A pattern is not automatically a solution; select it from user goal, data scale, constraints and context.

## Initial catalog
Search & Filter; Table/List; Pagination; Modal/Dialog; Form; Wizard/Stepper; Empty State; Error State.

## Pattern unit requirements
Purpose; use_when; avoid_when; anatomy; behavior; states; edge_cases; accessibility; validation; Figma guidance; related patterns.
