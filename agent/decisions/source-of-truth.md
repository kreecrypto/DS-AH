# Decision — Source of Truth

Evaluate authority using:

1. explicit approval
2. canonical Core DS ownership
3. product Master Screen designation
4. published/local domain component ownership
5. scenario evidence
6. recency/current status
7. state/responsive completeness

Blocked by default:
- Archived
- Deprecated
- Legacy
- screenshot-only
- PDF-only
- exploratory option sections
- unknown duplicate variants

A scenario section can define flow evidence without owning Core UI primitives.
