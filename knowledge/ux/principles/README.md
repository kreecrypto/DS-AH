# UX Principles

Cross-plane rules used during reasoning and review.

## Core principles
- Usability: effective, efficient and understandable task completion.
- Accessibility: support diverse abilities, input methods and assistive technology.
- Consistency: equivalent concepts and actions behave predictably.
- User control: preserve context, provide reversible actions where appropriate and communicate consequences.
- Error prevention: prevent avoidable mistakes before relying on error messages.
- Visibility of system status: expose loading, progress, success, failure and delayed outcomes.
- Recognition over recall: keep necessary choices/context visible.
- Progressive disclosure: reveal complexity when it becomes relevant.

Principles are constraints, not decoration. Pattern selection and visual decisions should be traceable to them.
