# 03 Structure — How

Define information architecture and interaction behavior.

## Required knowledge
IA, navigation model, user flow, task flow, interaction model, decision points, happy path, alternate path, exception path and recovery flow.

## Agent checks
Can the user understand where they are? Is the shortest valid path clear? Are decisions explicit? Can users recover from mistakes, interruption, retry, refresh or abandonment without losing context?

## Output
IA, flow model, decision/recovery logic and interaction specification.
