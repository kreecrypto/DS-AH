# Cognitive Psychology for UX

Use cognitive principles as explanatory tools, not rigid laws.

## Working memory and cognitive load
Reduce unnecessary simultaneous choices and memory requirements. Externalize important context.

## Recognition over recall
Expose relevant choices, history and state instead of requiring memory.

## Hick-style choice complexity
As meaningful choices increase, decision effort can rise. Group, prioritize and progressively disclose without hiding necessary options.

## Fitts-style target acquisition
Frequently used or important targets should be sufficiently easy to acquire. Consider target size, spacing and pointer/touch context.

## Gestalt grouping
Use proximity, similarity, alignment and common region to communicate relationships.

## Serial position and hierarchy
Prioritize important information and actions rather than relying on arbitrary ordering effects.

## Progressive disclosure
Show essential information first and reveal advanced complexity when relevant.

## Agent rule
Never cite a cognitive principle as proof that a design is correct. Use it to form a hypothesis, then validate against the task and users.
