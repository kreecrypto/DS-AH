# UX Validation

Validation closes the reasoning loop; a finished screen is not evidence that the UX works.

## Layers
1. Heuristic review — identify principle/pattern violations.
2. Usability testing — observe task completion and breakdowns.
3. Accessibility QA — keyboard, focus, semantics, contrast and assistive-technology considerations.
4. Design QA — compare implementation against approved UX, design system and Figma source.
5. Evidence — retain traceable findings, decisions, states tested and outcomes.

## Agent completion gate
Flow Proven → Evidence Proven → Adversarial Proven.

Check happy path plus relevant refresh, retry, abandon, technical failure, duplicate action, permission and device/responsive variations before declaring a critical flow complete.
