# UX Research Knowledge

## Purpose
Provide evidence before design decisions. Separate observed evidence, interpretation, assumption and hypothesis.

## Core methods
- Interviews: motivations, mental models, language and context.
- Contextual inquiry: behavior in the real environment.
- Usability testing: task behavior and breakdowns.
- Surveys: attitudes at scale; avoid treating self-report as observed behavior.
- Analytics: behavioral signals and funnels.
- Diary studies: longitudinal behavior.
- Competitive/reference review: patterns and expectations, not proof of user need.

## Research framing
Define question → target participants → method → task/questions → evidence → synthesis → insight → opportunity → design implication → validation.

## Evidence quality
Record source, participant/population, date, context, method and limitations. Never convert an unsupported assumption into a user fact.

## Agent rules
Use available evidence first. Explicitly label assumptions. Do not invent personas, pain points, quotes or metrics. Recommend validation when evidence is insufficient.
