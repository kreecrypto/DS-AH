# 04 Skeleton — Where

Turn structure into usable screen anatomy and hierarchy.

## Required knowledge
Wireframes, screen anatomy, information hierarchy, navigation, interface patterns, forms, tables/lists, search/filter, CTA hierarchy, responsive behavior and accessibility structure.

## Agent checks
Is the primary task visually obvious? Is information ordered by user priority? Are controls located near the objects they affect? Are repeated patterns consistent? Are focus order and responsive behavior defined?

## Output
Screen anatomy, wireframe guidance, component/pattern selection, responsive rules and interaction states.
