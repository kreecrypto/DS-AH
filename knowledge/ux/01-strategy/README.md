# 01 Strategy — Why

Define user needs and product/business objectives before features or screens.

## Required knowledge
- User needs and context of use
- Problem framing
- User research and evidence
- Personas/segments when evidence supports them
- Jobs To Be Done
- Pain points
- UX hypotheses
- Success metrics

## Agent checks
Who is the user? What are they trying to accomplish? What problem is evidenced? What outcome matters to the user and product? What assumptions remain unvalidated?

## Output
Problem statement, user need, objective, constraints/assumptions, hypothesis and measurable success criteria.
